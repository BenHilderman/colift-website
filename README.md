# CoLift website

The live CoLift marketing site at https://colift.fit/. Static HTML, self-hosted fonts, actual app captures and small vanilla-JS interactions.

The site follows the workout loop: find a workout, train with creator captures, share your version. Upcoming-update screenshots and disabled video imports are explicitly identified.

See [DEPLOY.md](DEPLOY.md) for preview, validation and the existing Git-connected deployment. Screenshot provenance is in [_handoff/screenshot-provenance.json](_handoff/screenshot-provenance.json).
